# SimplePress

WordPress-inspired administration theme and secure admin toolkit for GetSimple CMS CE.

## Installation

1. Copy `simplepress.php` and the `simplepress/` folder into `plugins/`.
2. Enable **SimplePress** in the GetSimple plugin manager.
3. Open **SimplePress → Appearance** to choose the color scheme.
4. If you used the old `wp_simple_admin` plugin, its database and settings are
   imported automatically on first use when the old files are present.

- GetSimple CMS CE, PHP 7.4–8.x.
- No runtime request to WordPress or public CDNs.
- Does not modify GetSimple core files.
